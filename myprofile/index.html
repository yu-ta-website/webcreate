SKILL

HTML/CSS

Webサイトに掲載する画像の配置、装飾、文字のデザイン、余白の調整などの対応が可能です。また、PCやスマホで見ても表示が崩れないレスポンシブ対応も可能です。

PHP

Webサイトのヘッダーやトップページ、サイドバー、投稿ページ、検索結果のページ、フッターに至るまでのコーティングが可能です。また、関数を使って実装することも可能です。

JavaScript

自動スクロールなど動きのあるWebサイトを作成することが可能です。

WordPress

店舗のHPなど、ノーコードでWebサイトを0から作成することが可能です。また、プログラミング言語や関数を使ってWebサイトを0から構築することも可能です。

Studio

店舗のHPなど、ノーコードでWebサイトを0から作成することが可能です。また、タブレットやスマホでもデザインが崩れないようにレスポンシブ対応も可能です。

Adobe Photoshop

画像や文字のデザインの編集、切り抜き、合成、ぼかし、遠近法、サイズの縦横比の調整等などWebサイトに必要不可欠なデザインを作成することが可能です。

Figma

広告バナーの作成、画像の編集、切り抜き、文字のデザイン等などWebサイトに必要不可欠なデザインを作成することが可能です。
